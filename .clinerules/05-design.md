# Packmetry design rule

Follow the Packmetry bootstrap for the active visual direction.

Character:
- elegant, sober, minimal, premium, calm, trustworthy
- precision physical-world tool
- white / near-white dominant surfaces
- deep navy and muted forest as functional accents
- Inter for headings/UI emphasis; Source Sans 3 for body where the production design keeps that direction

Avoid:
- purple/blue AI gradients
- neon cyan/purple
- glowing borders
- glassmorphism as the main language
- aurora/mesh backgrounds
- floating blobs, sparkles, robots, cyberpunk motifs
- excessive pills
- excessive cards-within-cards
- generic vibe-coded filler

Do not use legacy HTML as production architecture. Implement approved visual references as reusable Astro/React components with explicit design tokens and semantic accessibility.

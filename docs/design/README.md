# Packmetry Design References

The Packmetry bootstrap names `packmetry_updated_design(1).html` as the strongest current visual reference.

That exact file was **not** present in the supplied foundation set used to build this package, so no legacy CartonLab HTML has been promoted to current design authority.

The supplied `cartonlab_latest_code(1).html` is preserved only at:

`docs/reference/legacy/cartonlab_latest_code.html`

Do not implement the production homepage from that legacy file unless a later approved Packmetry design task explicitly authorizes using a specific part of it.

When the current Packmetry HTML is supplied, place an exact reviewed copy in this directory and update this README only after review.
